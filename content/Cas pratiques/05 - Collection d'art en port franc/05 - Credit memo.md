# Credit memo (cas 5)

Dossier : [[Cas pratiques/05 - Collection d'art en port franc/00 - Mandat|Mandat]] · [[Cas pratiques/05 - Collection d'art en port franc/01 - Client|Client]] · [[Cas pratiques/05 - Collection d'art en port franc/02 - Actif|Actif]] · [[Cas pratiques/05 - Collection d'art en port franc/03 - Dette existante|Dette existante]] · [[Cas pratiques/05 - Collection d'art en port franc/04 - Prêteurs pressentis|Prêteurs pressentis]] · [[Cas pratiques/05 - Collection d'art en port franc/05 - Credit memo|Credit memo]] · Correction

Gabarit d'une page à remplir. Chaque rubrique pose sa question et donne le repère ; écris ta réponse dans la dernière colonne.

| Rubrique | Question | Repère | Ta réponse |
|---|---|---|---|
| Demande | Combien, pour quoi, sur quelle durée, pour qui ? | le besoin net, pas le brut |  |
| Base retenue | Quelles œuvres comptent, à quelle valeur ? | l'expert du prêteur, l'éligibilité, le plafond par artiste |  |
| Titre et garde | Chaque œuvre est-elle au client, et qui la tiendra pour le prêteur ? | provenance, détention par une société, dépositaire |  |
| Prêteurs | Qui peut regarder ce dossier ? | la contrainte propre de chaque prêteur |  |
| LTV | Quel prêt brut maximal chez le prêteur retenu ? | 50 % de la base retenue |  |
| Brut et net | Combien le client reçoit-il vraiment ? | brut moins frais |  |
| Intérêts | Qui paie les intérêts, et avec quoi ? | revenu libre |  |
| Covenant | Quelle baisse des valeurs casse le covenant ? | 60 % de la base retenue |  |
| Sortie | Comment le prêt sera-t-il remboursé, quand ? | cession attendue, vente d'œuvres |  |
| Verdict | Bankable ou non, chez qui, à quel montant, à quelle condition ? | la contrainte la plus serrée |  |
| Structure et sûretés | Quel prêt, quelles sûretés, quelles conditions ? | voir le chapitre sur l'art |  |
