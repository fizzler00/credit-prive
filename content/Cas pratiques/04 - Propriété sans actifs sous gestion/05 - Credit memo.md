Gabarit d'une page à remplir. Chaque rubrique pose sa question et donne le repère ; écris ta réponse dans la dernière colonne.

| Rubrique | Question | Repère | Ta réponse |
|---|---|---|---|
| Demande | Combien, pour quoi, sur quelle durée, pour qui ? | le solde dû, pas le montant d'origine |  |
| Valeur | Quelle valeur retenir ? | l'expertise du prêteur, et la valeur de réalisation forcée |  |
| Prêteurs | Qui peut regarder ce dossier ? | la contrainte propre de chaque prêteur |  |
| LTV | Quel prêt brut maximal chez le prêteur retenu ? | le plus bas des deux plafonds |  |
| Brut et net | Combien les clients reçoivent-ils vraiment ? | brut moins réserve moins frais |  |
| Intérêts | Qui paie les intérêts, et avec quoi ? | revenu libre, réserve, liquidités |  |
| Sortie | Comment le prêt sera-t-il remboursé, quand ? | vente, retour en banque, liquidité attendue |  |
| Verdict | Bankable ou non, chez qui, à quel montant, sur quelle durée ? | la contrainte la plus serrée |  |
| Structure et sûretés | Quel prêt, quelles sûretés, quelles conditions ? | voir le chapitre immobilier |  |
